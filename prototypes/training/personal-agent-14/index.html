方法 01 · 清楚表达 Skill

把要求写好，
让 Agent 每次照着检查。

改写前 · 真实邀请节选

有问题可以直接截图圈出位置，再简单说一下原因；喜欢的图片也可以告诉我们。

改写后 · 教学示例

有问题时，可以在截图上圈出，并说明原因。

也可以告诉我们，你喜欢哪些图片。

先说行动 · 句子短一点 · 保留条件与未知项

借用 ASD-STE100 的清晰原则；不宣称符合整套英文标准。

方法 02 · 按用途选形式

看不进去，
换一种表达。

“做一段短视频，按顺序解释这个过程。”

教学示意：用一张图说明工作过程。

真实 HTML 成果：同页保留问题、原图和依据。

方法 03 · 搭建检查工作流

复杂任务，
先设计分工与检查。

主 Agent

分工与推进

明确目标、步骤和检查点

→
监控子 Agent

独立核对

对照原始材料与要求

→
主 Agent 汇总

按结果处理

暂停相关步骤，修正后再核对

范围有没有超出目标？
输入有没有遗漏材料？
结果是否满足要求？
依据关键结论有来源吗？

套图案例：查出未确认的旧图，新生图前暂停。
