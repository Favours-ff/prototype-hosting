二、国内平台兼容改造要点（前后端）

  1. 平台筛选框扩展：整个批量任务功能涉及的所有平台下拉筛选框，均需新增以下国内平台选项： 淘宝、天猫、京东、拼多多、1688。
  2. 修改库存 - 库存位置配置：当操作类型为「修改库存」时，页面上的库存位置读取库存表的配置数据；测试与上线阶段需手动配置一条仓库位置数据，按平台维度将所有国内平台地址统一设置为同一个默认位置数据。

该模块与「国内各平台商品数据拉取入库存表（DEMO-4936）」配套，用于承接各国内平台的批量改库存与批量改价执行。
