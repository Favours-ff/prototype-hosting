请求与回包示例

请求示例仅列业务参数与网关。公共鉴权参数见上表。

Shopee

店铺级签名按 partner_id + path + timestamp + access_token + shop_id 拼接，使用绑定应用密钥做 HMAC-SHA256。

SPE020_ID_BT 的指标回包节选

{
  "metric_id": 3,
  "metric_name": "non_fulfillment_rate",
  "current_period": 0.46,
  "last_period": 0.96,
  "unit": 2,
  "target": { "value": 10, "comparator": "<" }
}

unit=2 的这项指标当前为 0.46%，上期为 0.96%。

TikTok Shop

调用 open-api.tiktokglobalshop.com。用同店同应用的 shop_cipher 和卖家授权。按官网规则签名，避免 Query 与签名参数不一致。

TIK001_TH_BT 的历史成功单日参数

start_date_ge=2026-11-07
end_date_lt=2026-11-08
granularity=1D
currency=LOCAL

泰国店这组参数取 11 月 7 日。历史留有一条日区间的成功摘要。当前 105005 的请求号为 202611271016429E708108EB98511A53A7。

Lazada

菲律宾请求网关为 https://api.lazada.com.ph/rest。签名以 /seller/metrics/get 开头，签好后再编码 Query，输出大写十六进制签名。

入库规则

  • Shopee 健康和 Lazada 服务快照用 站点 + 平台店铺 ID + 当地采集日期 去重。TikTok 经营数据用 站点 + 平台店铺 ID + 当地统计日期 去重，按首期固定的 LOCAL 口径保存。
  • Lazada 生意参谋日数据用 站点 + 平台店铺 ID + 当地统计日期 去重，记录导出来源、导入时间和报表原始行。同日重导按同一统计日更新。
  • 保留 ERP 店铺 ID、接口路径或版本、采集时间、request_id 和原始业务 JSON。平台大 ID 用字符串，金额用定点小数并附原币。
  • 业务成功才更新指标。Shopee 看 error，TikTok 和 Lazada 看 code，兼容各自返回的类型。请求失败、空指标和真实零值分别记录，补拉时按原日期更新。
