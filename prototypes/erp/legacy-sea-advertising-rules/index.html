TikTok 字段映射

每日拉取前一天的广告数据，存入数据中心 tiktok_gmv_max_list。按 shop_id＋period 汇总成每店每天一行。旧需求注明接口金额为 USD，报表提供原币与人民币金额。

Lazada 取数

限「东南亚本土运营」部门的店铺。Python 每天从店铺后台导出前一天的推广数据并写入数据库。

项目后台来源取值逻辑
店铺广告余额营销中心 → 超级推广 → 总览 → 账户余额按站点取原币，一店只取一次。人民币余额按对应日期的云易盒中转汇率换算。
全效宝营销中心 → 超级推广 → 数据洞察 → 全效宝 → 推广计划 → 导出旧截图确认曝光量、点击数、直接转化订单对应 Impression、Clicks、Direct Orders。
超级新星营销中心 → 超级推广 → 数据洞察 → 超级新星（旧版本）→ 推广计划 → 导出同店同日有两类计划时，合计各计划的投放数据。余额为同一账户余额，取一次。

异常预警

#410 的 Shopee、Lazada 店铺适用。命中多项就提示全部原因。钉钉消息带店铺别名、日期、异常原因，并 @ 对应运营人员。

异常触发条件提示内容

ACOS 偏高ACOS ≥ 12.5%检查关键词精度及出价。
亏损推广单次转化成本-RMB ≥ 广告客单价-RMB × 20%检查链接是否适合投放广告。
